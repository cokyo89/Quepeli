# QuePeli

App Android: haces una foto a la pantalla (o eliges/compartes una captura) y te dice qué película o serie es, con póster, sinopsis, nota y dónde verla en España.

- Reconocimiento: Gemini (capa gratuita de Google AI Studio).
- Ficha: TMDB (API gratuita para uso personal).

## Claves (gratis)
1. **Gemini**: https://aistudio.google.com/apikey → "Create API key".
2. **TMDB** (opcional): crea cuenta en themoviedb.org → Ajustes → API → solicita clave (uso personal).

Se ponen en la app, en **⚙ Ajustes**. No van dentro del código.

## Compilar la APK
Sube este proyecto a un repositorio de GitHub (rama `main`). GitHub Actions compila solo y publica `QuePeli.apk` en **Releases**. Descárgala desde el móvil e instálala (permite "instalar apps desconocidas").

## Uso
- 📷 Hacer foto a la tele, o 🖼 elegir de la galería.
- También puedes **compartir** una captura desde cualquier app → QuePeli.
